# Django Blog Platform

A multi-author Django blog platform with:

- Multiple authors
- Categories and tags
- Media management
- Comments and reactions
- Bookmarks and author follows
- Search and feeds
- SEO and sitemap
- Advanced Django admin
- Faker development data

## Project apps

- accounts
- core
- blog
- media
- social
- analytics
- discovery
- seo
